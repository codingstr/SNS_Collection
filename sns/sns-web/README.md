# SNS 모아보기 사용법

인스타그램·X·유튜브의 새 글을 한곳에서 봅니다. 아무것도 설치할 필요 없이 **로그인만** 하면 됩니다.
글은 서버가 대신 모아 둡니다. 서버 설치·실행 방법은 저장소 맨 위의 [README](../README.md)를 보세요.

## 시작하기

1. 서버 주소(관리자가 알려 준 ngrok 주소)에 접속합니다. 처음 접속하면 ngrok 안내 화면이 한 번 나올 수 있습니다.
2. 아이디(영문·숫자 3~30자)와 비밀번호(6자 이상)로 **가입** → 이후엔 **로그인**. 위쪽에 "서버와 연결됨"이 뜨면 준비 끝입니다.
3. PC·휴대폰 어디서 로그인해도 같은 추적 계정과 글이 보입니다.

## 계정 추가

**추적 계정 관리** 화면에서 합니다.

- **이름으로 검색**: 매체를 고르고 이름을 입력해 *이름으로 검색* → 결과에서 계정 선택. 서버가 검색하는 데 몇 초 걸립니다.
- **주소/@핸들로 추가**: 매체를 고르고 `@핸들`이나 프로필 주소를 입력해 *추가*.
  - 유튜브 영상 주소나 사이트 메인 주소(내 피드)는 추가할 수 없습니다. 채널·프로필 주소를 넣으세요.
- **가져올 기간**: 계정마다 최근 7·14·30·60일 중에서 정합니다.
- **묶음 이름**(선택): 같은 사람·브랜드의 유튜브·X·인스타 계정에 같은 묶음 이름을 주면 한 줄로 모아 볼 수 있습니다. 이미 추가한 계정은 선택한 뒤 *묶기*로 묶습니다(이름을 비우면 해제).
- 계정을 추가하면 그 계정의 글을 바로 한 번 모읍니다.

## 글 가져오기

- **지금 최신화**: 내 추적 계정 전체를 지금 바로 모읍니다. 진행 상황은 오른쪽 *현재 작업* 카드에 보입니다.
- **자동 수집**: 서버가 켜져 있으면 1시간마다 알아서 모읍니다. 화면을 열어 두지 않아도 됩니다.
- 위쪽 매체 아이콘: 서버 테스트 계정이 로그인돼 있으면 색이 있고, 회색이면 관리자가 로그인해야 합니다. 로그인된 아이콘을 누르면 그 매체 수집을 켜고 끕니다.

## 보기

- **탭**: 사람별 / 유튜브(영상·게시물) / X / 인스타그램. *사람별*은 묶음 하나를 고르면 그 사람의 글을 매체별 줄로 보여 줍니다.
- **줄 넘기기**: 카드 줄 위에서 마우스 휠, 카드를 잡고 좌우로 끌기. 줄의 **전체 보기**를 누르면 그 계정의 글만 격자로 봅니다.
- **검색·정렬**: 위쪽 통합 검색은 제목·내용·작성자·매체·묶음을 찾습니다.

## 글 열기

- 카드를 누르면 화면 안에서 열립니다. 임베드가 안 되는 글(인스타 릴스 등)은 *새 창으로 열기*를 쓰세요.
- **‹ ›** 버튼, 키보드 **← →**, 바깥 회색 영역에서 마우스 휠로 이전/다음 글로 넘어갑니다. **Esc**나 **×**로 닫습니다.
- 열어 본 글은 카드가 **흐리게** 바뀌고, 이 표시는 내 계정에 저장되어 다른 기기에서도 똑같이 보입니다.

## 이어보기

각 줄 제목 옆의 두 버튼을 누르면 해당 글이 바로 열립니다.

- **‹ 최신글 이어보기**: 가장 최근에 본 글보다 더 새로운 안 본 글
- **이전글 이어보기 ›**: 안 본 글 중 가장 최신 글

## 계정 관리

위쪽 프로필 버튼 → 설정에서 합니다.

- **비밀번호 변경**: 현재 비밀번호를 확인한 뒤 바꿉니다. 다른 기기의 로그인은 모두 풀리고 이 기기는 유지됩니다.
- **계정 삭제**: 비밀번호를 확인하고 두 번 눌러야 삭제됩니다. 아이디와 추적 계정·설정·본 글 기록이 지워집니다.
- 비밀번호를 잊으면 복구할 수 없습니다(이메일을 받지 않는 구조). 새 아이디로 가입하세요.

## 문제가 생기면

- *서버와 연결되지 않았습니다*: 서버가 꺼져 있을 수 있습니다. 서버가 다시 켜지면 자동으로 이어집니다.
- 화면이 예전 그대로면 `Ctrl+Shift+R`로 강력 새로고침하세요.
- 특정 매체 글이 안 들어오면 위쪽 매체 아이콘이 회색인지 확인하고 관리자에게 알려 주세요.
